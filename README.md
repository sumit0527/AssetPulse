# Project Name - AssetPulse 

Preventive maintenance and breakdown management system built using Python and MySQL.

## Problem:

Small organizations often track machine maintenance manually in notebooks and only fix machines after they break.
Since managers cannot easily check repair history, maintenance schedules, or downtime, they don't know when a machine needs service, which causes unexpected delays. 

## Solution:

AssetPulse provides a system to manage all assets in one place—including maintenance schedules, equipment breakdowns, assigned technicians, and complete repair history.
